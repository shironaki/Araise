# SHADOW ASCENDANT — «Портальный охотник»

Аркадный экшен-рогалик на чистом JavaScript и Canvas: заходишь в портал, выкашиваешь
охотников, **поднимаешь павших врагов как теней** и ведёшь теневую армию на Хранителя врат.
Побеждённые тени остаются в хранилище и выходят с тобой в следующий портал.

**Статус:** играбельная версия 1.1.1 · без сборки, без зависимостей, без сервера.
**Технологии:** HTML + CSS + JavaScript (ES2021), WebAudio, Canvas 2D, `localStorage`.

---

## 1. Как запустить

Никаких сборок и установок — это статические файлы.

| Способ | Что сделать |
|---|---|
| Локально | Открыть `index.html` в браузере (двойной клик) |
| Локальный сервер | `npm run serve` → http://localhost:8080 (или `python3 -m http.server 8080`) |
| GitHub Pages | Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` |

Проверка кода и баланса (нужен Node 18+, зависимостей нет):

```bash
npm test        # 160 функциональных проверок в headless-режиме
npm run balance # прогон автоигроками: новичок и опытный игрок по 8 порталов
```

## 3. Игровой цикл

1. **Охота.** Волны врагов идут, пока не выполнена цель портала (цель = `24 + портал × 7`
   убийств). Со дна арены подбираются трупы: `E` рядом с трупом превращает его в тень.
2. **Хранитель врат.** Когда цель выполнена и арена зачищена, появляется босс: он толще,
   бьёт больнее и каждые 5 секунд зовёт подмогу. Перед боем охотник восстанавливает 30 % HP.
3. **Итоги.** Победа: тени из боя возвращаются в хранилище, портал повышен, открываются
   врата следующего ранга. Поражение: тени, вышедшие с тобой, растворяются, но резерв
   в хранилище остаётся — можно пробовать снова.

### Прогресс и сохранение

- **Хранилище (vault)** — «склад» теней между порталами, лимит 500.
- Перед охотой из хранилища выводится `armyMax` теней (по умолчанию 8, растёт усилением
  «Командир теней»); остальные ждут в резерве.
- Ключ `localStorage`: `shadow-ascendant` (`{v, portal, shadows[], clears, kills, best}`).
- Совместимость: читаются старые сохранения вида `{portal, vault}` — число превращается в
  солдат; повреждённый JSON и мусор в массиве теней игнорируются, игра стартует с нуля.
- Настройка звука хранится отдельно в `shadow-ascendant-muted`.

### Ранги порталов

`E → D → C → B → A → S` — по два портала на ранг. С ростом портала растут HP,
урон и скорость врагов, размер волн и цель охоты, а Хранитель врат становится
прочнее (в том числе пропорционально размеру твоей теневой армии).

## 4. Контент

**Враги** (в скобках — базовые характеристики, дальше масштабируются порталом):

| Тип | HP | Скорость | Урон | Опыт | Появляется |
|---|---|---|---|---|---|
| Охотник | 30 | 58 | 7 | 16 | всегда |
| Бегун | 20 | 105 | 5 | 20 | всегда |
| Брут | 90 | 37 | 13 | 28 | с портала 2 |
| Проклятый | 42 | 45 | 9 | 32 | с портала 3 |
| Хранитель врат (босс) | (560 + 130 × портал) × сила армии¹ | 56 + 3 × портал | 12 + 1.4 × портал | 60 | финал охоты |

¹ Сила армии = `1 + 0.15 × число теней в бою`: чем больше твоя свита, тем прочнее
Хранитель, поэтому бой остаётся испытанием и с полной армией, и без неё.

Размер волны = `4 + 2 × номер волны + ⌊0.6 × портал⌋`, интервал появления врагов 0.32 с.


**Тени** (поднимаются из соответствующих врагов, урон растёт с номером портала):

| Тень | Урон | Скорость | Интервал атаки |
|---|---|---|---|
| Воин тени | 10 | 165 | 0.62 с |
| Тень-бегун | 8 | 210 | 0.48 с |
| Тень-брут | 15 | 125 | 0.82 с |
| Тень-проклятый | 13 | 150 | 0.72 с |
| Тень Хранителя | 20 | 118 | 0.95 с |

**Усиления** (по 3 случайных на уровень): Клинок тени (+14 урона), Живучесть
(+35 HP и лечение), Шаг сквозь тьму (+45 скорости), Разрыв (+18 дальности),
Командир теней (+1 к армии), Ярость теней (+30 % урона теней), Холодный расчёт
(−20 % перезарядки), Тёмная плоть (регенерация), Жатва (+3 HP за убийство).

## 6. Технические решения

- **Один файл игры, IIFE + `'use strict'`** — нет глобального мусора, нет сборщика.
- **Мир в CSS-пикселях.** `ResizeObserver` пересчитывает размер арены, canvas
  масштабируется по `devicePixelRatio` (до 2×), градиенты перестраиваются — игра
  одинаково чёткая на телефоне и на 4K-мониторе.
- **Фиксированный шаг не нужен:** `dt` ограничен 0.033 с, поэтому после сворачивания
  вкладки игра не «телепортирует» врагов через пол-арены.
- **Гистерезис на границах радиусов** (`APRON`): без него юнит из-за погрешности
  плавающей точки застревает ровно на границе касания и не наносит урон.
- **Производительность:** O(n²) расталкивание только для врагов и теней (не больше
  ~20 объектов), частицы ограничены 420 штуками, трупы — 60 (старшие растворяются
  первыми), HUD обновляется через сравнение значений, чтобы не трогать DOM зря.
- **Интерфейс опционален.** Все обращения к DOM идут через обёртки `show/hide/
  setClass/bind/listen`: можно вырезать `#stick`, `#touch`, `#bossbar`, `#banner`
  или `#choices` — игра останется играбельной (усиления тогда берутся клавишами
  `1/2/3`). Без `#canvas` модуль не падает, а пишет в консоль и отключается.
- **Звук** синтезируется WebAudio на месте (осцилляторы + огибающая) — ни одного
  аудиофайла. Контекст создаётся на первый клик и будится при любом состоянии,
  кроме `running` (это же лечит `interrupted` на iOS после звонка); закрытый
  браузером контекст пересоздаётся. На «🔇» контекст засыпает через `suspend()`,
  а без `AudioContext` модуль молча отключается и кнопка честно показывает 🔇.
- **Доступность:** `aria-label` на иконочных кнопках, `:focus-visible`,
  `prefers-reduced-motion` (отключает и тряску арены, и красную вспышку урона —
  не только CSS-анимации), звук выключается одной кнопкой.
- **Шрифты** подключены `<link>`-ом в `index.html` с `preconnect` на `fonts.
  googleapis.com` и `fonts.gstatic.com`: `@import` в CSS добавлял ещё один
  блокирующий рендер запрос.
- **Отладка:** объект `window.ShadowAscendant` даёт доступ к состоянию, игроку и
  API (`start`, `pause`, `attack`, `raise`, `spawn`, `toggleSound`, …).

## 7. Проверки

`npm test` прогоняет игру в headless-режиме (заглушки DOM, Canvas, WebAudio и
`localStorage`) и проверяет 160 сценариев: запуск и волны, удар и перезарядка,
подъём тени, очередь усилений при нескольких уровнях за кадр, пауза, победа и
поражение, сохранение и восстановление прогресса, старый и битый формат
сохранений, сброс прогресса и его подтверждение, семь размеров арены (от 280×200
до 1920×1080), виртуальный стик и кнопки, клавиатуру, лимиты частиц и трупов,
двенадцать порталов подряд, синтез звука (разблокировка по клику, `suspend()` на
mute, поведение старых реализаций WebAudio без `state`/`suspend`), работу с
вырезанной разметкой и контракт `id` между `index.html` и скриптом.

`npm run balance` прогоняет автоигрока по порталам и печатает таблицу побед —
удобно проверять кривую сложности после правок баланса.

Текущая кривая (8 порталов, стартовое хранилище по 2 тени на портал):
«новичок» проходит 4 из 8, «опытный» — 8 из 8; дальше, с 10-го портала,
начинаются врата ранга S, где проигрывают оба профиля.

## 8. Что исправлено в версии 1.1.1

Проход по устойчивости: игра не должна падать на странных браузерах и в неполной
разметке, а тесты — оставлять без присмотра реальные пути.

- **`resume()` только для `suspended`** оставлял звук мёртвым после входящего
  звонка на iOS (`state === 'interrupted'`) и после `closed` — теперь контекст
  будится при любом состоянии кроме `running`, а закрытый пересоздаётся.
- **`suspend()` на выключенном звуке** — раньше «🔇» лишь переставал создавать
  осцилляторы, сам аудиопоток оставался активным.
- **Кнопка звука врала**, если `AudioContext` в браузере нет: `audio()` выключает
  звук сам, но 🔊 на кнопке оставался. Теперь и иконку, и подпись (включая
  `aria-label`) перерисовывает `syncSoundButton()`.
- **Обращения к DOM без проверок** роняли всю игру, если в разметке не хватало
  `#bossbar`, `#banner`, `#choices` или тач-панели; появились обёртки
  `show/hide/setClass/bind/listen` и корректный выход при отсутствии `#canvas`.
- **Лимита трупов не было**, хотя тест его проверял (`CORPSE_MAX = 60`), —
  затяжной бой наращивал массив бесконечно.
- **Подтверждение сброса прогресса оставалось «взведённым»**: надпись
  «нажми ещё раз» не гасла после 4 секунд, а второй клик позже уже ничего не
  стирал. Отсчётка сбрасывается в цикле кадров, «залипший» текст возвращается.
- **Задержка «touch + click» была общей на все кнопки** — тап по ⚔ глушил клик
  по ✦ в следующие полсекунды. Отметка теперь своя у каждой кнопки, время
  берётся из `performance.now()` (не зависит от перевода часов).
- **Опыт Хранителя** брался из константы `55` вместо `bossConfig().xp` — правка
  таблицы врагов не доходила до боя.
- **Стартовый экран** показывал «ВСЕГО ПОБЕД» рядом с числом убийств и молчал про
  рекорд портала (`meta.best` уже сохранялся) — метки приведены к смыслу.
- **`@import` шрифтов** в `style.css` блокировал первый рендер; перенесён в
  `index.html` рядом с `preconnect`.
- **Тесты** научились подсовывать игру без части разметки и с заглушкой WebAudio;
  проверка версии читает `package.json`, а не жёстко зашитую строку.

## 9. Что было исправлено в версии 1.1.0

Код приведён в рабочее состояние: из исходной заготовки не запускались бой и
прогресс. Ключевые правки:

- **Тени не били врагов.** Из-за погрешности плавающей точки юнит застревал ровно
  на границе радиуса удара. Добавлен гистерезис `APRON` для теней и врагов.
- **Усиления «съедались».** Если за один кадр умирало несколько врагов, все уровни
  после первого терялись; экран усиления не переключался на следующий уровень.
  Теперь уровни копятся в очереди `pending`, а выбор идёт по одному.
- **Босс умирал за 2 секунды.** HP Хранителя теперь масштабируется порталом и
  размером теневой армии, бой длится 8–15 секунд.
- **Утечка теней между охотами.** Тени прошлого боя не растворялись, из-за чего
  их можно было размножить; выход из портала («Покинуть портал») вообще отсутствовал.
- **`spawn()` без типа падал** (`enemyTypes[undefined].radius`), а босс брал статы
  врага-меча — оба случая переписаны на явные конфиги.
- **Битое сохранение ломало запуск** (`JSON.parse` без try/catch, мусор в массиве).
- **Хардкод размера 960×600** игнорировал `canvas.width/height` — теперь размер
  берётся из арены, учитывается `devicePixelRatio`.
- **`setTimeout` из волн продолжал спавнить** после паузы и выхода; заменён на
  детерминированную очередь `spawnQueue`.
- **Прозрачные/битые состояния интерфейса:** не сбрасывались оверлеи между боями,
  не обновлялся счётчик хранилища после подъёма тени, не было итогов боя.
- **Мобильная версия:** арена 9:12, safe-area, кнопки боя, стик с `pointercancel`,
  защита от двойного срабатывания «touch + click».
- **Лимиты и мелочи:** частицы ограничены, ключи не «залипают» при потере фокуса,
  игра ставится на паузу при сворачивании вкладки, добавлены звук, сброс прогресса,
  полоса HP босса, объявления волн, четыре новых усиления и два новых типа врагов.
